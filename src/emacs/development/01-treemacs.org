* Auto-open on Treemacs Switch Workspaces =C-x t w=

As I like to have treemacs open whenever i'm working on a project I
always had to open treemacs, and then switch to the correct project.
This got me a bit annoyed doing it every time, so this piece of advice
will automatically open treemacs if not already visible after
switching to a project.

#+begin_src emacs-lisp
;; advice to run after swithcing workspace
(defun jf/show-treemacs-on-switch-workspace--advice (&optional args)
  "Automatically open treemacs window on switching workspace.  Does nothing if already visible"
  (pcase (treemacs-current-visibility)
    ('exists (treemacs-select-window))
    ('none (treemacs--init))))

(advice-add 'treemacs-switch-workspace :after #'jf/show-treemacs-on-switch-workspace--advice)
#+end_src
